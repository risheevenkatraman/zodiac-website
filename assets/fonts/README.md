Locally hosted font subsets matching the Zodiac design reference at
https://zodiac-website-iota.vercel.app/.

- Libre Caslon Display, regular: headings.
- Libre Caslon Text, italic: editorial accents and player star labels.
- Hanken Grotesk, variable weights 100–900: body copy, navigation, and controls.

The original WOFF2 subset filenames are retained from the reference. Face
definitions and Unicode coverage are in `css/fonts.css`, imported by the shared
stylesheet. All fonts use `font-display: swap` with system fallbacks.

The accompanying SIL Open Font License files come from the respective families
in https://github.com/google/fonts/tree/main/ofl.
